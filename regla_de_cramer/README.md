# Regla de Cramer
Programa interactivo para resolver sistemas lineales Ax = b usando la Regla de Cramer.

Uso rápido:
1. Ejecutar: `python src/main.py`
2. Ingresar el número de incógnitas `n` o presionar Enter para usar `n=2`.
3. Pulsar Enter cuando se pregunte por la matriz para que el programa genere
   un sistema de ejemplo aleatorio e invertible.
4. Alternativamente, ingresar la matriz `A` fila por fila y el vector `b` manualmente.

El programa imprime la matriz, calcula los determinantes y muestra la solución.
