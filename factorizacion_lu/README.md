# Factorización LU
Programa interactivo que calcula la factorización LU con pivoteo parcial
y resuelve sistemas lineales Ax = b.

Uso rápido:
1. Ejecutar: `python src/main.py`
2. Ingresar tamaño `n` (Enter usa `n=3`) y elegir autocompletar o entrada manual.
3. Ingresar `b` o pulsar Enter para autocompletar con ceros.
4. El programa muestra `P`, `L`, `U`, la solución `x` y el determinante aproximado.
